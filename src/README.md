# Registro de Uso de Inteligência Artificial – SRC

## Projeto: Tech Tennis

Este documento apresenta o registro da utilização de ferramentas de Inteligência Artificial durante o desenvolvimento do código-fonte do projeto Tech Tennis.

### 1. Ferramentas utilizadas

- Claude.ai

### 2. Finalidade de uso

A ferramenta foi utilizada como apoio para:

- Explicar o funcionamento dos códigos Arduino.
- Identificar e corrigir possíveis erros de programação.
- Esclarecer dúvidas sobre sensores e atuadores.
- Compreender a lógica de funcionamento dos componentes eletrônicos.
- Auxiliar na compreensão da comunicação entre os componentes do sistema.
- Entender como conectar e realizar a comunicação entre o aplicativo Android e o Arduino.
- Compreender como enviar comandos do aplicativo para o Arduino, permitindo o controle dos componentes eletrônicos.
- Entender como conectar o aplicativo Android ao banco de dados Firebase.
- Compreender como armazenar, consultar e atualizar informações dos usuários e dados dos treinamentos no Firebase.
- Auxiliar na compreensão da troca de informações entre o aplicativo, o Arduino e o banco de dados.

### 3. Prompts principais utilizados

- Explique o funcionamento deste código Arduino.
- Corrija os possíveis erros deste código.
- Explique para que serve a função `pulseIn()`.
- Explique como funciona o sensor ultrassônico.
- Ajude a entender a comunicação entre o Arduino e os componentes eletrônicos.
- Explique como conectar o aplicativo Android ao Arduino.
- Ajude a entender como funciona a comunicação entre o aplicativo e o Arduino.
- Explique como enviar comandos do aplicativo para o Arduino.
- Explique como conectar o aplicativo Android ao Firebase.
- Ajude a entender como salvar e consultar dados no Firebase.
- Explique como armazenar informações dos usuários e registros dos treinamentos.
- Ajude a compreender a troca de informações entre o aplicativo, o Arduino e o banco de dados.

### 4. Trechos ou entregas afetadas

- Programação do Arduino.
- Código de controle dos componentes eletrônicos.
- Código relacionado aos sensores e atuadores.
- Testes e correções do código-fonte.
- Integração entre o aplicativo Android e o Arduino.
- Comunicação e troca de informações entre o aplicativo e o Arduino.
- Integração do aplicativo Android com o banco de dados Firebase.
- Armazenamento, consulta e gerenciamento de dados no Firebase.
- Gerenciamento das informações dos usuários e dos registros de treinamento.
- Comunicação e troca de informações entre as diferentes partes do sistema.

### 5. Responsabilidade

Os integrantes do grupo são responsáveis pela revisão, compreensão, validação e funcionamento final do código-fonte. A ferramenta de Inteligência Artificial foi utilizada apenas como apoio, não substituindo a participação dos integrantes no desenvolvimento, nos testes e na validação do sistema.
