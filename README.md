O projeto tem como objetivo utilizar o Arduino para desenvolver uma solução que permita que mais pessoas tenham contato com o tênis de uma forma acessível, interativa e divertida.

A nossa ideia é criar um sistema semelhante a um jogo de pontuação. O sistema utilizará um laser para indicar um ponto específico onde o jogador deverá tentar acertar a bola de tênis. Depois do golpe, sensores e câmeras poderão verificar se a bola atingiu ou não a região indicada.

Quando o jogador acertar o alvo, o sistema registrará um acerto e adicionará pontos à sua pontuação. Caso a bola não atinja o local indicado, será registrado um erro. Ao final do treino, o sistema poderá apresentar os resultados, como a quantidade de acertos, erros e a porcentagem de precisão do jogador.

Dessa forma, o projeto busca transformar o treino de precisão do tênis em uma experiência gamificada, permitindo que o jogador acompanhe seu desempenho enquanto pratica.
